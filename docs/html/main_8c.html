Detailed Description

Point d'entrée principal de l'émulateur Chip-8.

Ce fichier initialise les différents modules de l'émulateur : -mémoire -processeur -affichage (SDL) -clavier -son -interface utilisateur

Il gère également la boucle principale, les événements SDL et l'exécution de l'émulation Chip-8.
