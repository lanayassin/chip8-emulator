Detailed Description

Déclaration des handlers d'opcodes Chip-8 et table de dispatch.

Ce fichier contient les prototypes des focntions responsables des instructions Chip-8. Il contient aussi la table de dispatch permettant d'associer les opcodes à leur handler correspondant.
